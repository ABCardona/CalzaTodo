# Capturas de pantalla

Coloca aqui las capturas que respaldan la entrega. Los nombres sugeridos son los
que usa el README.

| Archivo | Que debe mostrar |
|---|---|
| `1-catalogo.png` | La pagina cargada con los zapatos de la categoria `Shoes` |
| `2-busqueda.png` | El buscador con un texto escrito y el filtrado de resultados |
| `3-orden.png` | El desplegable de "Ordenar por" con el catalogo reordenado por precio |
| `4-detalle.png` | Una tarjeta con el boton "Ver detalle" abierto y sus miniaturas |
| `5-husky-bloqueo.png` | La terminal con el commit rechazado por ESLint |
| `6-husky-exito.png` | La terminal con el commit completado tras corregir el error |

Sugerencias para que las capturas se vean bien:

- Agranda la ventana del navegador y hazla de al menos 1200 px de ancho.
- Para la captura 5 y 6 deja la terminal con la fuente un poco mas grande
  (`Ctrl` + rueda) para que se lea el mensaje de error de ESLint.
- Una sola imagen por archivo, sin recortes raros ni ediciones.
